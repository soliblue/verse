# Local open-weight coding agents complete 87.9% of data-prep tasks

> Researchers tested whether coding agents can clean sensitive study data without sending it to a cloud model. Open-weight models with 31 to 35 billion parameters completed up to 87.9% of a new benchmark on locally controlled hardware.

The benchmark turns cleaning scripts for six sweeps of a British cohort study into 20 tasks covering 102 variables. Tasks include harmonizing categories and merging records across different survey waves.

The framework runs the agent against a known correct dataset, then checks both its R code and the data it produces. This matters for health and population research, where governance rules can forbid sending personal data to an external model provider.

The result is author-reported from a new preprint and one carefully curated workflow. It shows that local agents can be useful in this setting, not that they can safely clean arbitrary research data without expert review.

## Why this was selected

It gives open-weight models a concrete advantage beyond ideology: they can bring agentic coding into data environments that cloud systems are not allowed to enter.
